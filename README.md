## ✨ Features

*   **100% Pure CSS Responsiveness**: Built entirely with native CSS Media Queries, Flexbox, and Grid to ensure a seamless user experience across all devices (mobile, tablet, and desktop).
*   **Zero Framework Dependencies**: No Tailwind, Bootstrap, or heavy external CSS libraries. Lightweight, fast-loading, and written from scratch.
*   **Mobile-First Approach**: The layout is structured to prioritize mobile performance and scale up beautifully for larger screens.

## 🛠️ Tech Stack

*   **HTML5**: Semantic and accessible document structure.
*   **Pure CSS3**: Advanced layout techniques (Grid/Flexbox) and custom responsive styling.

## 📱 Responsive Breakpoints
*   **Mobile Layout**: Default styling for compact screens.
*   **Tablet Layout (`@media (min-width: 768px)`)**: Optimized for mid-sized viewports.
*   **Desktop Layout (`@media (min-width: 1024px)`)**: Expands to full-width desktop monitors.
